Como jogar

Para jogar, basta clicar na tela para fazer Porcello bater as asas e subir. Cada clique mantém o porquinho no ar, então é preciso controlar o tempo certo para desviar dos obstáculos e não cair. Quanto mais você avança, maior fica o desafio!
